# UTCP for Dart

Dart packages for the [Universal Tool Calling Protocol (UTCP)](https://github.com/universal-tool-calling-protocol/utcp-specification).

| Package | Transports |
| --- | --- |
| [`utcp`](packages/utcp) | Core client, `http` (with OpenAPI conversion), `sse`, `streamable_http`, `text` |
| [`utcp_mcp`](packages/utcp_mcp) | `mcp` (MCP servers over stdio and streamable HTTP) |
| [`utcp_cli`](packages/utcp_cli) | `cli` |
| [`utcp_file`](packages/utcp_file) | `file`, `.env` variable loader |
| [`utcp_socket`](packages/utcp_socket) | `tcp`, `udp` |
| [`utcp_websocket`](packages/utcp_websocket) | `websocket` |
