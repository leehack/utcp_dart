# UTCP for Dart

Dart packages for the [Universal Tool Calling Protocol (UTCP)](https://github.com/universal-tool-calling-protocol/utcp-specification).

| Package | Transports |
| --- | --- |
| [`utcp`](packages/utcp) | Core client, `http` |
| [`utcp_mcp`](packages/utcp_mcp) | `mcp` (MCP servers over stdio and streamable HTTP) |
